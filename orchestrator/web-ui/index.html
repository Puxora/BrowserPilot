一键部署 Chrome 浏览器扩展

为了让 AI 与您的 Chrome 浏览器无缝通信，您需要安装 BrowserPilot 浏览器扩展：

  1. 点击右侧按钮，一键打包并下载扩展的压缩包。
  2. 解压下载到的 chrome-extension.zip 文件夹。
  3. 在 Chrome 浏览器中访问 chrome://extensions/，在右上角开启开发者模式。
  4. 点击加载已解压的扩展程序，选中刚刚解压出来的文件夹。
